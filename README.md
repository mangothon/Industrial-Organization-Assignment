# 2023 산업연관표 분석 웹앱

산업조직론 과제물 1. 한국은행 「2023년 산업연관표(연장표)」의 대분류·중분류·소분류·기본부문 투입산출표를 브라우저에서 불러와 원자료를 살펴보고, 국산품 최종수요가 늘 때의 파급효과를 계산하는 웹앱입니다. 별도 서버 없이 방문자의 브라우저에서 Pyodide(WebAssembly 기반 Python)로 계산합니다.

## 사용법

1. **분류 선택**: 상단에서 대분류(33)·중분류(83)·소분류(165)·기본부문(380) 중 하나를 고릅니다.
2. **불러오기**: `불러오기` 버튼을 누르면 해당 Excel을 내려받아 읽고 계수를 검증합니다. 처음 한 번은 Python 환경 준비에 10~20초가 걸리고, 기본부문(12MB)은 읽기에 시간이 더 걸립니다. 한 번 불러온 분류는 다시 고르면 바로 사용할 수 있습니다.
3. **원자료 탐색** 탭
   - 왼쪽에서 12개 시트 중 하나를 고르면 시트의 의미·단위·읽는 방향(행/열)이 설명됩니다.
   - 부문×부문 시트(거래표·투입계수·유발계수)는 히트맵으로 전체 구조를 보여줍니다. 칸을 누르면 그 행이 아래 표에 펼쳐집니다.
   - `행으로 보기`(배분구조)와 `열로 보기`(투입구조)를 전환하고, 대분류 필터와 검색으로 행·열을 찾습니다.
4. **파급효과 시뮬레이터** 탭
   - 산업을 고르고 증가액(억원·조원·백만원)을 넣어 시나리오에 추가합니다. 여러 산업을 넣으면 합산됩니다.
   - `파급효과 계산`을 누르면 생산·부가가치·수입 유발액, 생산유발 승수, 직접·간접효과, 13개 산업군별 효과, 상위 15개 산업, 전체 산업 표가 나옵니다.
   - 결과 전체는 CSV(백만원 단위)로 내려받을 수 있습니다.

## 분석 방법

| 기호 | 의미 |
|---|---|
| Ad | 국산투입계수 행렬 |
| Am | 수입투입계수 행렬 |
| L = (I − Ad)⁻¹ | 생산유발계수 행렬 |
| M = Am · L | 수입유발계수 행렬 |
| V = v̂ · L | 부가가치유발계수 행렬 (v̂: 부가가치율 대각행렬) |
| f | 국산품 최종수요 증가 벡터 (입력값) |

- 생산유발액 x = L·f, 수입유발액 m = M·f, 부가가치유발액 va = V·f
- 직접효과 = f, 간접효과 = x − f, 생산유발 승수 = Σx ÷ Σf
- 국산품 수요 1원은 부가가치 또는 수입으로 모두 나뉘므로 Σva + Σm = Σf 가 성립합니다(화면에서 확인 표시).

**계수 검증**: 자료를 불러올 때 원자료의 계수표들이 위 관계를 만족하는지 직접 계산해 확인합니다(허용 오차 1e-8).
1. (I − Ad)·L = I
2. Am·L = 수입유발계수표
3. v̂·L = 부가가치유발계수표
4. 각 열에서 수입유발 + 부가가치유발 = 1

**국내 생산이 없는 부문**: 원유·천연가스(LNG)·유연탄·천연고무·원당(기본부문)과 원유 및 천연가스(소분류)는 국내 생산이 0이라 국산품 수요 증가를 줄 수 없습니다. 시뮬레이터에서 선택할 수 없고, 검증 4는 이 부문들을 빼고 확인합니다.

**산업군**: 결과의 13개 산업군은 한국은행 보도자료의 분류(소비재·기초소재·조립가공제품, 생산자·사회·소비자서비스 등)를 따르며, 부문분류표로 모든 분류의 부문을 대분류에 연결해 묶었습니다.

## 단위

| 자료 | 단위 |
|---|---|
| 거래표, 최종수요 항목별 유발액 | 백만원 (화면에서는 크기에 따라 억원·조원으로 표시, 원자료 열에 백만원 그대로 표시) |
| 투입계수 | 비율 (단위 없음, 투입액 ÷ 총투입액) |
| 생산·수입·부가가치 유발계수 | 배 (최종수요 1원당 유발액, 단위 없음) |
| 최종수요 항목별 표의 구성비 | % |
| 환산 | 1억원 = 100백만원, 1조원 = 1,000,000백만원 |

## 파일 구조

```
index.html          화면 구성 (탭, 입력·결과 영역)
style.css           화면 디자인
app.js              버튼 동작, 표·차트·히트맵 표시
worker.js           별도 작업 공간(Web Worker)에서 Pyodide 실행
model.py            Excel 읽기, 계수 검증, 탐색·시뮬레이션 계산
.nojekyll           GitHub Pages가 Jekyll 처리 없이 정적 파일을 게시하도록 설정
data/io-2023-33.xlsx    대분류 투입산출표 (33개 부문)
data/io-2023-83.xlsx    중분류 투입산출표 (83개 부문)
data/io-2023-165.xlsx   소분류 투입산출표 (165개 부문)
data/io-2023-380.xlsx   기본부문 투입산출표 (380개 부문)
data/sector-classification.xlsx  부문분류표 (기본→소→중→대 분류 연결)
```
