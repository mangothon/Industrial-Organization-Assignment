# 2023 산업연관표 분석 웹앱

산업조직론 과제물 1. 한국은행 「2023년 산업연관표(연장표)」의 대분류·중분류·소분류·기본부문 투입산출표와 주요 분석표를 브라우저에서 불러와 원자료를 살펴보고 비교하며, 경제구조와 산업연관효과를 분석하고, 국산품 최종수요가 늘 때의 파급효과를 계산하는 웹앱입니다. 별도 서버 없이 방문자의 브라우저에서 Pyodide(WebAssembly 기반 Python)로 계산합니다.

## 시작하기

1. **분류 선택**: 상단에서 대분류(33)·중분류(83)·소분류(165)·기본부문(380) 중 하나를 고릅니다.
2. **불러오기**: `불러오기` 버튼을 누르면 해당 Excel을 내려받아 읽고 계수를 검증합니다. 처음 한 번은 부문분류표와 주요 분석표도 함께 내려받고, Python 환경 준비에 10~20초가 걸립니다. 기본부문(12MB)은 읽기에 시간이 더 걸립니다. 한 번 불러온 분류는 다시 고르면 바로 사용할 수 있습니다.
3. 상단 **검증 패널**(✓ 계수 검증 통과)을 펼치면 계수표 관계 검증과 취업유발 검증 결과를 볼 수 있습니다.
4. 원자료 비교의 선택과 시뮬레이터 시나리오는 **분류마다 따로 기억**합니다. 분류를 바꾸면 그 분류의 상태가 나오고, 돌아오면 이전 상태가 복원됩니다.

## 탭별 사용법

### 1. 원자료 탐색 (`#explorer`)
- 왼쪽에서 12개 시트 중 하나를 고르면 시트의 의미·단위·읽는 방향(행/열)이 설명됩니다.
- **가장 큰 연결**: 부문×부문 블록에서 자기 부문(대각) 거래를 뺀 상위 15개를 "공급 산업 → 사용 산업" 막대로 보여줍니다. 막대를 누르면 그 공급 산업이 아래 프로필과 표에 선택됩니다. 최종수요 항목별 시트에서는 숨깁니다.
- **산업 프로필**: 아래 `행·열 펼쳐보기`에서 고른 산업의 요약입니다(합계·지표 항목을 고르면 안내만 표시).
  - 거래표: 총산출·수출률·중간투입률·수입의존도·부가가치율, 투입구조(국산 중간재/수입 중간재/부가가치, 분모 총투입), 배분구조(중간수요/소비/투자/수출, 분모 총수요), 주요 구매처·판매처 상위 5개(같은 눈금, 자기 부문 거래는 따로 표기). 수입·국산 거래표는 그 표의 값으로 계산할 수 있는 지표만 보여줍니다.
  - 투입계수: 생산 1원당 투입 상위 8개(열), 이 상품을 많이 쓰는 산업 상위 8개(행), 열합(중간투입률 의미).
  - 유발계수: 이 산업 수요 1원이 끌어올리는 산업 상위 8개(열), 이 산업을 끌어올리는 수요 상위 8개(행), 자기 부문 값. 생산유발계수는 열합·행합·영향력계수·감응도계수도 표시합니다.
  - 최종수요 항목별 유발액: 선택 산업의 최종수요 항목별 구성(민간소비/정부소비/투자/수출)과 7개 항목 표.
- **행·열 펼쳐보기**: `행으로 보기`(배분구조)와 `열로 보기`(투입구조)를 전환하고, 대분류 필터와 검색으로 행·열을 찾습니다.

### 2. 원자료 비교 (`#compare`)
사용자가 행과 열을 직접 골라 맞춤 비교표를 만듭니다.
- 도구 막대: 시트 선택, `⇄ 행·열 바꾸기`, 표시 방식 `금액(원값) | 열 비중 % | 행 비중 %`, `나머지 합계 표시`(기본 켜짐), `CSV 다운로드`, `행/열 수정`, 표 단위.
- **행/열 수정 창**: 맨 위 `행 수정 | 열 수정`을 오가며 행과 열을 한 번에 고친 뒤 `적용`을 누르면 표에 반영됩니다(`취소`·Esc는 반영하지 않음).
  - 이미 추가한 항목은 체크된 상태로 보이며, 체크를 풀면 삭제됩니다. 추가된 묶음(13개 산업군·사용자 묶음)은 목록 맨 위에 따로 보입니다.
  - 검색, `전체 선택`·`전체 해제`(목록에 보이는 항목), `전체 삭제`(지금 보고 있는 축에 추가된 항목을 묶음까지 모두 삭제), 빠른 선택(13개 산업군·부가가치 항목·최종수요 항목·합계 항목), 대분류(대분류 화면이면 13개 산업군) 단위 묶음 체크박스를 제공합니다.
  - `행·열 같게`는 기본으로 꺼져 있고, 이 창에서 켜면 보고 있는 축의 선택을 다른 축에 복사한 뒤 양쪽을 함께 고칩니다.
- 행만 고르면 열에, 열만 고르면 행에 **전체 산업**(현재 분류의 개별 산업 전부)이 표시됩니다. 표의 각 행·열 이름 옆 ✕로 바로 삭제할 수도 있습니다.
- 나머지 합계: 선택하지 않은 산업 전체의 합을 "나머지 산업 합계" 행·열로 붙이고, 금액 거래표에서는 부가가치계(9690)·총투입계(9790) 행도 붙입니다(회색 배경).
- 비중: 열 비중 % = 값 ÷ 열 합계, 행 비중 % = 값 ÷ 행 합계. 분모는 나머지 합계를 포함한 산업 전체에 선택한 구성 항목(부가가치 항목·최종수요 항목 등)을 더한 값입니다. 합계 성격의 항목(9590·9790·9290 등)은 분모에 넣지 않습니다.
- 산업 칸은 값 크기에 따라 순차 파랑으로 옅게 칠하고, 표 전체를 한 단위(억원 또는 조원, 계수 시트는 계수)로 통일합니다.
- 산업 묶기: 금액 시트에서 행·열 이름 앞 □를 골라 이름을 넣고 `묶기`를 누르면 값을 합산한 사용자 묶음이 됩니다. 계수 시트에서는 단순 합산이 성립하지 않아 막아 둡니다.
- 선택 항목이 50개를 넘으면 느려질 수 있다는 안내를 띄웁니다.
- 처음 빈 화면의 예시 버튼("1차 금속·컴퓨터전자·운송장비 비교", "13개 산업군 거래 구조")은 부문분류표로 찾은 현재 분류의 대응 산업을 씁니다.

### 3. 경제구조 (`#structure`)
선택한 분류의 2023년 투입산출표로 계산합니다(⑤만 주요 분석표).
1. **핵심 지표**: 총산출·부가가치·중간투입률·부가가치율·수입의존도·국산화율·수출률·수입률. 한국은행 공표치와 0.1%p(금액은 0.1조원) 이내면 ✓를 붙입니다.
2. **산업구조**: 13개 산업군의 총산출·부가가치 구성 100% 막대와 금액·구성비 표.
3. **투입구조**: 중간투입률·부가가치율·수입의존도·국산화율 순위(13개 산업군 또는 불러온 분류 전체 상위·하위 15개), 전산업 평균선.
4. **배분구조**: 최종수요 구성(소비·투자·수출, 공표치 48.0/22.6/29.4%와 비교), 산업별 수출률·중간수요율 순위.
5. **2020~2023 변화**: 주요 분석표의 8개 지표를 13개 산업군 + 전산업 꺾은선으로 보여줍니다. 산업군은 최대 4개까지 색으로 강조하고, 표에 4개년 값과 2023−2022 차이를 둡니다.

### 4. 산업연관효과 (`#linkage`)
1. **유발계수 순위**: 생산유발계수 열합을 "자기 부문(대각)"과 "다른 부문으로 파급(열합 − 대각)"으로 나눈 막대와 전산업 평균선. 부가가치·수입 유발계수는 산업마다 합이 1인 100% 막대로 보여주고 부가가치 몫 순으로 정렬합니다. 13개 산업군 보기는 산출액 가중 평균입니다.
2. **영향력·감응도 4분면**: x = 영향력계수(9801 행), y = 감응도계수(9802 열), 기준선 1. 점 크기 = 총산출 옵션, 검색한 산업은 주황으로 강조합니다. 아래에 4개 영역(핵심 연관산업·최종재형·중간재·기반형·독립형)별 산업 목록과 해석을 둡니다.
3. **최종수요 항목별 유발**: 최종수요 항목별 생산·부가가치·수입 유발계수(9811 행) 비교, 산업별 생산유발액의 최종수요 항목 구성, 수출 의존도 상위 15개 산업.
4. **고용유발**: 주요 분석표의 취업(전체 취업자)·고용(임금근로자) 계수와 유발계수를 덤벨 차트로 보여줍니다. 연도 선택(2020~2023), 대분류 33개 또는 13개 산업군 보기. 단위는 명/10억원이며, 선이 길수록 다른 산업에서 생기는 일자리가 많습니다.

### 5. 파급효과 시뮬레이터 (`#simulation`)
- 산업을 고르고 증가액(억원·조원·백만원)을 넣어 시나리오에 추가합니다. 여러 산업을 넣으면 합산됩니다.
- `파급효과 계산`을 누르면 생산·부가가치·수입·취업자 유발, 생산유발 승수, 직접·간접효과, 13개 산업군별 효과(`생산 | 취업자` 전환), 상위 15개 산업, 전체 산업 표가 나옵니다. 결과 전체는 CSV(백만원·명 단위)로 내려받을 수 있습니다.
- **분류 수준별 비교**: 현재 시나리오를 부문분류표로 더 큰 분류(현재 → 소 → 중 → 대)로 옮겨 같은 계산을 하고, 분류별 생산유발액·승수·부가가치·수입·취업자와 승수 막대를 보여줍니다. 아직 불러오지 않은 분류는 자동으로 불러옵니다.

## 지표 정의와 계산식

| 기호 | 의미 |
|---|---|
| Ad | 국산투입계수 행렬 |
| Am | 수입투입계수 행렬 |
| L = (I − Ad)⁻¹ | 생산유발계수 행렬 |
| M = Am · L | 수입유발계수 행렬 |
| V = v̂ · L | 부가가치유발계수 행렬 (v̂: 부가가치율 대각행렬) |
| f | 국산품 최종수요 증가 벡터 (입력값) |

**파급효과**
- 생산유발액 x = L·f, 수입유발액 m = M·f, 부가가치유발액 va = V·f
- 직접효과 = f, 간접효과 = x − f, 생산유발 승수 = Σx ÷ Σf
- 국산품 수요 1원은 부가가치 또는 수입으로 모두 나뉘므로 Σva + Σm = Σf 가 성립합니다(화면에서 확인 표시).

**경제구조 지표** (코드는 투입산출표의 행·열 코드)

| 지표 | 정의 |
|---|---|
| 총산출 | 총거래표 9790(총투입계) 합계 |
| 중간투입률 | 중간투입계(9590) ÷ 총투입계(9790) |
| 부가가치율 | 부가가치계(9690) ÷ 총투입계(9790) |
| 수입의존도 | 수입거래표 중간투입계(9590) ÷ 총거래표 총투입계(9790) |
| 국산화율 | 국산거래표 중간투입계(9590) ÷ 총거래표 중간투입계(9590) |
| 수출률 | 수출(9140) ÷ 총산출(9310) |
| 수입률 | 수입계(9329) ÷ 총공급계(9390) |
| 중간수요율 | 중간수요계(9090) ÷ 총수요계(9290) |
| 최종수요 구성 | 소비(9111+9112), 투자(9121+9122+9131+9132), 수출(9140) ÷ 최종수요계(9190) |

산업군 값은 금액을 합산한 뒤 비율을 계산합니다.

**산업연관효과 지표**
- 생산유발계수 열합 = L의 열 합계(그 산업 최종수요 1원이 경제 전체에 일으키는 생산), 대각 = 자기 부문 몫
- 영향력계수 = 열합 ÷ 열합 평균(후방연쇄), 감응도계수 = 행합 ÷ 행합 평균(전방연쇄) — 원자료 생산유발계수 시트의 9801 행·9802 열
- 최종수요 항목별 유발계수 = 항목별 유발액 ÷ 항목별 최종수요액(9811 행). 수입유발에는 수입 최종재 구매가 포함되어 부가가치·수입 유발계수의 합이 항목에 따라 1과 다를 수 있습니다.
- 수출 의존도 = 최종수요 항목별 생산유발액의 수출(9140) ÷ 최종수요계(9190)

## 계수 검증

자료를 불러올 때 원자료의 계수표들이 위 관계를 만족하는지 직접 계산해 확인합니다(허용 오차 1e-8).
1. (I − Ad)·L = I
2. Am·L = 수입유발계수표
3. v̂·L = 부가가치유발계수표
4. 각 열에서 수입유발 + 부가가치유발 = 1

대분류와 주요 분석표가 모두 준비되면 대분류 생산유발계수 L과 2023년 취업계수 e로 계산한 e·L을 주요 분석표의 2023년 취업유발계수(19번 시트)·고용유발계수(20번 시트)와 비교합니다. 각주 "1)"이 없는 28개 대분류에서 오차가 1e-6 미만이면 ✓로 표시합니다. 각주 "1)"이 붙은 5개(A 농림수산품, B 광산품, C14 제조임가공, F 건설, T 기타)는 통합표(1·7·13부문) 기준이라 비교에서 제외합니다.

## 취업자 유발 (근사 방식)

- 생산유발액 x를 대분류로 묶은 X_k(백만원)에 2023년 대분류 취업계수 e_k(명/10억원)를 곱해 **취업유발 = Σ e_k·X_k ÷ 1000** 으로 계산합니다. 고용(임금근로자)도 고용계수로 같은 방식입니다. 산업별 취업자는 그 산업 x × 그 산업이 속한 대분류 취업계수 ÷ 1000 입니다.
- 대분류에서는 주요 분석표의 취업유발계수와 정확히 같은 결과가 나옵니다(위 검증). 중분류·소분류·기본부문에는 산업별 취업계수가 공표되지 않아 대분류 취업계수를 그대로 쓰므로, 화면에 "대분류 취업계수 적용 근사치"로 표시합니다.

## 분류 수준 비교의 한계

- 시나리오는 더 큰 분류로만 옮길 수 있습니다(기본 → 소 → 중 → 대). 큰 분류의 한 부문을 작은 분류의 여러 부문으로 나누는 기준이 없기 때문입니다. 4단계를 모두 비교하려면 기본부문에서 시나리오를 만드세요.
- 큰 분류일수록 여러 산업의 평균 투입구조를 쓰므로 결과가 달라집니다(집계 편의). 예: 대분류 운송장비에는 승용차뿐 아니라 선박·항공기도 포함됩니다.

## 국내 생산이 없는 부문

원유·천연가스(LNG)·유연탄·천연고무·원당(기본부문 0621·0622·0612·0194·0841)과 원유 및 천연가스(소분류 062)는 국내 생산이 0이라 국산품 수요 증가를 줄 수 없습니다. 시뮬레이터에서 선택할 수 없고, 비율 계산(0으로 나누기)과 순위·4분면에서 빼며, 프로필 등에서는 "국내 생산 없음"으로 표시합니다. 계수 검증 4는 이 부문들을 빼고 확인합니다.

## 산업군

13개 산업군은 한국은행 보도자료의 분류(농림수산품, 광산품, 소비재제품, 기초소재제품, 조립가공제품, 제조임가공·산업용 장비 수리, 전력·가스·수도 및 폐기물, 건설, 도소매 및 운송, 생산자서비스, 사회서비스, 소비자서비스, 기타)를 따르며, 부문분류표로 모든 분류의 부문을 대분류에 연결해 묶었습니다. 주요 분석표의 행 이름은 공백·가운뎃점·쉼표·각주 "1)"·"및"을 지우고 비교해 33개 대분류와 13개 산업군에 1:1로 연결합니다.
